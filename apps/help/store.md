# App Store
Install more apps from Flathub, or from Ubuntu where it has them too.

## Get an app
Search or browse, open an app's page and press Get. Remove takes it off again.

## Ubuntu or Flathub
Where Ubuntu has an app too, its page shows "Get it from" with both:
- **Ubuntu**: the system's own package. It runs on the system's libraries, so it fits in fully: an app built with Qt wears Huginn's look and puts its menus in the top bar. It updates with Software Update, and installing or removing it asks for your password.
- **Flathub**: from the people who make the app, usually newer, and in its own sandbox. It updates in the App Store. An app built with Qt brings its own Qt, so its look and menus stay inside its window.

Apps built with Qt start on Ubuntu's, everything else on Flathub's; pick the other before you press Get if you'd rather. Once an app is in, its page says which you have.

## Web apps
Web apps installed from the Huginn browser show in your installed list too.
