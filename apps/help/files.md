# Files
Browse, find and tidy everything on this computer, drives you plug in and network places.

## Find a file
Start typing in the search field to filter this folder. Press Enter to search its subfolders too, or choose "Inside files" to look inside documents and PDFs.

## Look without opening
Select a file and press Space for a quick look at pictures, videos, PDFs and text. The arrow keys move to the next one.

Pictures, videos, PDFs, documents, sheets and presentations show a small picture of themselves instead of an icon (a video a frame from it, a document its first page).

With Huginn AI on, Quick Look on a document, a PDF or a text file has Summarize: a few sentences on what it is and what matters in it. A summary is kept until the file changes, so it shows at once the next time.

## Copy, move and undo
Drag files onto a folder, a place on the left or a drive. Ctrl+C, Ctrl+X and Ctrl+V work as usual, and Ctrl+Z undoes the last rename, move, copy or move to Trash.

## Earlier versions of a file
Every hour, Huginn OS keeps a copy of your home folder as it was: each one from the last day, then one a day for a week (fewer when the disk is nearly full). Right-click a file and choose Earlier Versions… to see the times it was different. Open shows that version as it was; Put Back a Copy puts it beside the file, named with its time, so nothing is replaced. Caches and Steam's games aren't kept, so deleting a game frees its space at once. This needs Huginn OS installed by its own installer.

## Rename several at once
Select them all and choose Rename: they get a shared name and numbers.

## Tabs
Ctrl+T opens a tab, Ctrl+W closes it, and middle-clicking a folder opens it in a new tab.

## Network places
Choose a network place to connect to a shared folder or server (smb, sftp, ftp, WebDAV or NFS). Its address is remembered.

## Send things on
Right-click files for Send by Mail, Send to Phone, Print, Translate and Compress to .zip.

## When another app asks for a file
Open and Save windows in every app are Huginn's, with the same places as Files. Double-click a folder to go in, a file to choose it; hold Ctrl or Shift to choose several when the app allows. The app's own options (like an encoding) sit just above the buttons.
